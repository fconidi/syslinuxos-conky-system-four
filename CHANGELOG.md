# Changelog

## 0.3.0

- Rename the package to `syslinuxos-conky-system-four`; `syslinuxos-conky-window` remains as a transitional package.
- Rename the configuration, scripts and launchers to `conky-system-four-*`; an edited configuration is carried over.
- Use `CONKY_SYSTEM_FOUR_SCALE` for the scale override; `CONKY_WINDOW_SCALE` still works.

## 0.2.10

- Show the Conky-System-Four launcher names after installation.

## 0.2.9

- Show the window theme as Conky-System-Four in the Start and Stop menu entries.

## 0.2.8

- Use a single aggregate CPU bar above 32 logical processors so the panel remains within its width.

## 0.2.7

- Use the shared Conky icon for both Start and Stop menu entries.

## syslinuxos-conky-menu 0.1.1

- Give the Conky submenu its own scalable icon with colored rings.

## 0.2.6

- Group Start Window and Stop Window under System Tools > Conky.
- Add Italian launcher names.
- Install the shared syslinuxos-conky-menu package automatically.

## syslinuxos-conky-menu 0.1.0

- Add a shared Conky submenu for desktop monitor themes.
- Support additional themes through the X-SysLinuxOS-Conky category.
